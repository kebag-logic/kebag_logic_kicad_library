# Footprint Guideline

- Pin 1 marking
- Border around component
- Line widths
- Polarized capacitor marking
- Visible parameters
    - Component ID
    - Silk screen and fab are in the same position
- Invisible parameters
    - Everything except component ID
- Required layers
- Optional layers
- 3D Models are assigned to the respective footprint and are placed in the `3dmodels/` folder. The subfolder containing the step file must end with `.3dshaps`.
- Missing 3D models might be obtained from https://www.snapeda.com/ TODO: Check license.
